# Data Vortex – Round 1 Phase 1

## Overview

This repository contains the code notebooks for Round 1 Phase 1 of the Data Vortex challenge.

The work focuses on data cleaning, preprocessing, validation, and exploratory data analysis (EDA) of the social-media dataset.

## Datasets

The dataset contains two components:

- Social Engine Users
- Social Engine Posts

## Data Cleaning

The notebooks cover:

- Missing-value identification and handling
- Duplicate detection and removal
- Date and timestamp standardization
- Invalid value detection
- Negative engagement-value handling
- Final data validation

## Exploratory Data Analysis

The analysis includes:

- Language distribution
- Follower-count distribution
- Account creation activity over time
- Location distribution
- Platform distribution
- Engagement distribution
- Posting activity over time
- Top posts by engagement
- Correlation between engagement metrics

## Notebooks

The 'notebooks' folder contains:

- 'social_engine_users1.ipynb' – Users dataset cleaning and EDA
- 'social_engine_posts1.ipynb' – Posts dataset cleaning and EDA

## Reproducibility

The notebooks contain the Python code used for data cleaning, validation, and exploratory analysis.
